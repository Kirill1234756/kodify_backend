## ✅ РЕШЕНИЕ (выполнить на сервере):

### Шаг 1: Обновить код из Git

```bash
cd ~/projects/kodify/backend
git pull
```

### Шаг 2: Обновить токен в .env

Выполните эту команду (заменит старый токен на правильный):

```bash
sed -i 's/TELEGRAM_BOT_TOKEN=.*/TELEGRAM_BOT_TOKEN=8226522901:AAHJSZ8zpZ-UCSX4OTmKb_bLbl2FwTgzGyA/' .env
```

### Шаг 3: Проверить что токен обновился

```bash
grep TELEGRAM_BOT_TOKEN .env
```

**Должно показать:**

```
TELEGRAM_BOT_TOKEN=8226522901:AAHJSZ8zpZ-UCSX4OTmKb_bLbl2FwTgzGyA
```

**Обратите внимание на различия:**

- `UCSX4OTmKb` (заглавная **O**, не цифра 0)
- `bLbl2FwTgzGyA` (буква **l** перед цифрой 2, не 12)

### Шаг 4: Пересобрать и перезапустить контейнер

```bash
docker-compose build --no-cache backend
docker-compose up -d
```

Или если пересборка не нужна:

```bash
docker-compose restart backend
```

### Шаг 5: Проверить что код обновился в контейнере

```bash
docker-compose exec backend cat /app/src/server.ts | grep "test/telegram"
```

**Должна быть строка:**

```typescript
app.get('/api/test/telegram', async (req, res) => {
```

### Шаг 6: Проверить что токен правильный в контейнере

```bash
docker-compose exec backend env | grep TELEGRAM_BOT_TOKEN
```

**Должно показать:**

```
TELEGRAM_BOT_TOKEN=8226522901:AAHJSZ8zpZ-UCSX4OTmKb_bLbl2FwTgzGyA
```

### Шаг 7: Проверить API

```bash
curl https://api.kodifyweb.ru/api/test/telegram
```

**Должно вернуть:**

```json
{ "success": true, "message": "Telegram bot is working" }
```

## 🔍 Если всё равно не работает:

### Проверить логи контейнера:

```bash
docker-compose logs --tail=50 backend
```

### Проверить что контейнер запущен:

```bash
docker-compose ps
```

### Проверить что код компилируется:

```bash
docker-compose exec backend ls -la /app/dist/src/server.js
```

### Перезапустить полностью:

```bash
docker-compose down
docker-compose up -d --build
```
