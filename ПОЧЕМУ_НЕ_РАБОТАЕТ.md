## ✅ РЕШЕНИЕ:

### Шаг 1: Обновить код из Git

```bash
cd ~/projects/kodify/backend
git pull
```

### Шаг 2: Пересобрать контейнер (ОБЯЗАТЕЛЬНО!)

```bash
docker-compose build --no-cache backend
docker-compose up -d
```

**Важно:** Простой `docker-compose restart` НЕ загрузит новый код! Нужна пересборка образа.

### Шаг 3: Проверить что код обновился

```bash
docker-compose exec backend cat /app/src/server.ts | grep "test/telegram"
```

**Должна быть строка:**
```typescript
app.get('/api/test/telegram', async (req, res) => {
```

Если этой строки нет - код не обновился, нужно снова сделать `git pull` и `docker-compose build`.

### Шаг 4: Проверить API

```bash
curl https://api.kodifyweb.ru/api/test/telegram
```

**Должно вернуть:**
```json
{"success":true,"message":"Telegram bot is working"}
```

## 🔍 Если всё равно не работает:

### Проверить что код действительно в контейнере:

```bash
# Проверить что файл существует
docker-compose exec backend ls -la /app/src/server.ts

# Проверить что endpoint есть
docker-compose exec backend grep -n "test/telegram" /app/src/server.ts

# Проверить что TypeScript скомпилирован
docker-compose exec backend ls -la /app/dist/src/server.js
```

### Полностью пересоздать контейнер:

```bash
docker-compose down
docker-compose build --no-cache
docker-compose up -d
```

### Проверить логи:

```bash
docker-compose logs --tail=50 backend
```
