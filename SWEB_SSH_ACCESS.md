## 🔑 Где взять пароль для SSH

### Способ 1: Пароль в панели управления sweb.ru

1. Зайдите на https://sweb.ru
2. Перейдите в **"Виртуальные серверы"**
3. Выберите ваш VPS (`kirilltatn_vps_1`)
4. В разделе **"Доступ"** найдите:
   - Пароль (может быть скрыт, нажмите "Показать")
   - Или кнопку **"Сбросить пароль"** - сбросьте и получите новый пароль
   - Или кнопку **"Управление доступом"** - там должен быть пароль

### Способ 2: Пароль в email

- Проверьте email, указанный при регистрации на sweb.ru
- Там должно быть письмо с паролем для доступа к серверу

### Способ 3: Использование VNC консоли

Если SSH не работает или вы хотите войти через веб-консоль:

1. В панели sweb.ru нажмите **"Перейти в VNC-консоль"**
2. Когда появится запрос логина:

   ```
   89-111-142-190 login:
   ```

   **Введите:** `root` и нажмите Enter

3. Когда появится запрос пароля:

   ```
   Password:
   ```

   **Введите пароль:** `EJZ2JVsTFCWtR*TY` и нажмите Enter

   - ⚠️ Пароль тоже не будет виден при вводе

4. После успешного входа вы увидите приглашение:
   ```
   root@89-111-142-190:~#
   ```

**⚠️ ВАЖНО:** Не вводите `kirilltatn_vps_1` или `kirilltatn` - это НЕ имя пользователя!
Правильный логин всегда: **`root`**

## 🚀 Подключение через SSH

### На Windows (PowerShell или CMD)

**Выполните эту команду:**

```powershell
ssh root@89.111.142.190
```

**Что вводить пошагово:**

1. При первом подключении система спросит:

   ```
   The authenticity of host '89.111.142.190' can't be established.
   Are you sure you want to continue connecting (yes/no)?
   ```

   **Введите:** `yes` и нажмите Enter

2. Затем появится запрос пароля:

   ```
   root@89.111.142.190's password:
   ```

   **Введите пароль:** `EJZ2JVsTFCWtR*TY`

   - ⚠️ **Важно:** Пароль не будет виден при вводе (нет точек или звездочек) - это нормально!
   - Просто введите пароль и нажмите Enter

3. После успешного входа вы увидите:
   ```
   Welcome to Ubuntu 24.04.3 LTS
   root@89-111-142-190:~#
   ```

### На Windows (через PuTTY)

1. Скачайте PuTTY: https://www.putty.org/
2. Откройте PuTTY
3. В поле "Host Name" введите: `89.111.142.190`
4. Порт: `22`
5. Connection type: `SSH`
6. Нажмите "Open"
7. Введите логин: `root`
8. Введите пароль

### На Linux/Mac

```bash
ssh root@89.111.142.190
```

## ⚠️ Решение проблем

### Проблема: "Permission denied" или "Login incorrect"

**Решение:**

1. **Убедитесь, что используете правильный пользователь:**

   - На Ubuntu серверах sweb.ru используется `root`
   - ❌ **НЕ используйте:** `kirilltatn_vps_1` (это ID VPS в системе, видно в URL)
   - ❌ **НЕ используйте:** `kodify_vps` (это отображаемое имя в интерфейсе)
   - ❌ **НЕ используйте:** `kirilltatn` (это логин в панели sweb.ru, не на сервере)
   - ✅ **Используйте только:** `root`

2. **Проверьте пароль:**

   - Пароль чувствителен к регистру
   - Скопируйте пароль из панели sweb.ru, чтобы избежать опечаток
   - Если пароль содержит спецсимволы, вводите их внимательно

3. **Используйте VNC консоль:**
   - Если SSH не работает, войдите через VNC
   - Сбросьте пароль: `passwd root`
   - Попробуйте SSH снова

### Проблема: "Connection refused" или "Connection timed out"

**Решение:**

1. **Проверьте, что SSH включен в панели sweb.ru:**

   - В настройках VPS должна быть включена опция SSH
   - Если нет - включите её

2. **Проверьте файрвол:**

   - На sweb.ru порт 22 обычно открыт по умолчанию
   - Если нет - откройте порт 22 в настройках файрвола

3. **Проверьте IP адрес:**
   - Убедитесь, что используете правильный IP: `89.111.142.190`
   - IP может измениться при пересоздании VPS

### Проблема: SSH работает, но нужен другой пользователь

**Решение:**

1. **Создайте нового пользователя через VNC или SSH:**

   ```bash
   adduser your-username
   usermod -aG sudo your-username
   ```

2. **Подключитесь как новый пользователь:**
   ```bash
   ssh your-username@89.111.142.190
   ```

## 🔒 Настройка SSH ключей (рекомендуется для безопасности)

После первого входа через пароль, рекомендуется настроить SSH ключи:

### На Windows (PowerShell):

```powershell
# Генерируем SSH ключ (если его еще нет)
ssh-keygen -t ed25519 -C "your-email@example.com"

# Копируем ключ на сервер
type $env:USERPROFILE\.ssh\id_ed25519.pub | ssh root@89.111.142.190 "mkdir -p ~/.ssh && cat >> ~/.ssh/authorized_keys"
```

### На Linux/Mac:

```bash
# Генерируем SSH ключ (если его еще нет)
ssh-keygen -t ed25519 -C "your-email@example.com"

# Копируем ключ на сервер
ssh-copy-id root@89.111.142.190
```

После этого можно будет входить без пароля, только с ключом.
