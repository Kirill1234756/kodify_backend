# 🔧 Решение проблемы вставки в VNC терминал

## ❌ Проблема

В VNC консоли через браузер не работают:
- `Ctrl+V` → показывает `^V`
- `Ctrl+Shift+V` → показывает `^V`
- `Shift+Insert` → показывает другие символы

## ✅ Решение: Правый клик мыши

**Самый надежный способ вставки в VNC через браузер:**

1. **Скопируйте команду** (выделите и `Ctrl+C` в браузере/документе)

2. **В VNC терминале:**
   - **Кликните ПРАВОЙ кнопкой мыши** в области терминала
   - Текст автоматически вставится!

Это работает потому, что VNC через браузер правильно обрабатывает события мыши.

## 🎯 Пошаговая инструкция:

### Пример: Создание директории

1. Скопируйте эту команду:
   ```
   mkdir -p ~/projects/it-company
   ```

2. В VNC терминале кликните **правой кнопкой мыши**

3. Команда вставится

4. Нажмите `Enter`

## 🔄 Альтернатива: Использовать SSH вместо VNC

Если VNC неудобен для вставки, используйте SSH:

### На Windows (PowerShell):

```powershell
ssh root@89.111.142.190
```

В SSH терминале:
- **`Ctrl+Shift+V`** работает нормально
- Или **правый клик мыши** тоже работает

### Преимущества SSH:
- ✅ Быстрее работает
- ✅ Лучше поддерживает вставку
- ✅ Можно использовать в любом терминале

## 📝 Быстрые команды (можно ввести вручную)

Если правый клик тоже не работает, введите короткие команды вручную:

```bash
mkdir -p ~/projects/it-company
cd ~/projects/it-company
git clone https://github.com/Kirill1234756/kodify_backend.git backend
cd backend
ls -la
```

## 💡 Полезные советы:

1. **Для длинных команд** - используйте правый клик или SSH
2. **Для коротких команд** - проще ввести вручную
3. **Автодополнение** - нажимайте `Tab` для автодополнения путей
4. **История команд** - стрелки вверх/вниз показывают предыдущие команды
