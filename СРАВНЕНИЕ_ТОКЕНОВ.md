# 🔍 Сравнение токенов

## ✅ Правильный токен (из браузера - работает):

```
8226522901:AAHJSZ8zpZ-UCSX40TmKb_bLb12FwTgzGyA
                                        ↑
                                   ПОДЧЕРКИВАНИЕ (_)
```

## ❌ Токен в nano (в .env файле - НЕ работает):

```
8226522901:AAHJSZ8zpZ-UCSX40TmKb-bLb12FwTgzGyA
                                        ↑
                                     ДЕФИС (-)
```

---

## 🔴 НАЙДЕНО НЕСОВПАДЕНИЕ:

**Позиция:** После `TmKb` и перед `bLb12FwTgzGyA`

- **Правильно:** `TmKb_bLb` (подчеркивание `_`)
- **В nano:** `TmKb-bLb` (дефис `-`)

---

## ✅ ИСПРАВЛЕНИЕ:

В nano нужно изменить строку:

**БЫЛО:**

```
TELEGRAM_BOT_TOKEN=8226522901:AAHJSZ8zpZ-UCSX40TmKb-bLb12FwTgzGyA
```

**ДОЛЖНО БЫТЬ:**

```
TELEGRAM_BOT_TOKEN=8226522901:AAHJSZ8zpZ-UCSX40TmKb_bLb12FwTgzGyA
```

### Как исправить в nano:

1. Найдите строку с `TELEGRAM_BOT_TOKEN`
2. Найдите дефис `-` после `TmKb`
3. Удалите дефис и вставьте подчеркивание `_`
4. Сохраните: `Ctrl+O`, `Enter`, `Ctrl+X`
5. Перезапустите: `docker-compose restart backend`
